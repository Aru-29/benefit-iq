# Benefit IQ Frontend Web Application (`benefit-iq-fe`)

Angular standalone application for Benefit IQ featuring a Power BI / Tableau style Customer Utilization Dashboard, Admin Management Portal, Generic Autocomplete Lookup Component (`GenericLookupComponent<T>`), AI Assistant Chatbot Widget, and enterprise design system.

## Quick Start
```bash
# Install dependencies
npm install

# Start development server
npm start
```
Navigate to `http://localhost:4200`.

## Production Build
```bash
npm run build
```
