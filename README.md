# BenefitIQ

BenefitIQ is a prototype that helps card members and issuers understand benefit utilization. It combines an Angular 18 client with a FastAPI service, ClickHouse analytical storage and Redis-backed session state.

Start with [the setup guide](SETUP_GUIDE.md) to run the complete local stack. [The project documentation](PROJECT_DOCUMENTATION.md) describes the implemented workflows, architecture, data model, production limitations and prioritized roadmap.

This repository uses synthetic local data. It does not contain BigQuery, Tableau, issuer data feeds or independently measured model-accuracy results.
